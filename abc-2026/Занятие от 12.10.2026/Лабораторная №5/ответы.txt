Контрольные вопросы
1. Опишите последовательность Request-Response Cycle во Flask.

1) Браузер отправляет http запрос серверу
2) Flask определяет маршрут по url и http методу
3) Функция маршрута обрабатывает запрос и при необходимости получает данные из модели или базы данных
4) Данные передаются в шаблон через render_template()
5) Jinja2 подставляет значения и обрабатывает условия и циклы
6) Flask возвращает сформированный html в браузер
7) Браузер отображает страницу и загружает css, изображения и другие ресурсы из static


2. Для чего нужны папки templates и static?

templates хранит шаблоны HTML, например base.html, index.html
static хранит статические файлы (css, изображения, js файлы, шрифты и тд)


3. Что такое шаблонизатор и какие задачи он решает?

Шаблонизатор это инструмент для формирования html на основе шаблона и динамических данных, который позволяет выводить переменные, использовать условия и циклы и переиспользовать общие элементы страниц


4. В чём разница между {{ ... }} и {% ... %} в Jinja2?

{{ ... }} выводит значение выражения
{% ... %} выполняет управляющие конструкции (условия, циклы и тд)


5. Как работает наследование шаблонов?

Наследование даёт возможность создавать общий шаблон и использовать его на нескольких страницах
{% extends "base.html" %} - родительский шаблон
{% block content %}...{% endblock %} - определяет блок, содержимое которого дочерний шаблон может переопределить
Поэтому в меню, шапке и подвале не нужно повторяться


6. Что делает функция super() в Jinja2?

super() возвращает содержимое блока родительского шаблона, что позволяет дополнить родительский блок не удаляя его содержимое


7. Зачем нужна функция url_for()?

url_for() генерирует URL по имени маршрута или статического ресурса


8. Как передать данные из роутера в шаблон?

Данные передаются в render_template() в виде именованных аргументов


9. Приведите пример условного оператора и цикла в Jinja2.

Условие:
{% if user.nickname == 'Miguel' %}
    <p>Это наш администратор.</p>
{% else %}
    <p>Это обычный пользователь.</p>
{% endif %}

Цикл:
<ul>
    {% for i in range(1, 4) %}
        <li>Пункт {{ i }}</li>
    {% endfor %}
</ul>
